# MallaFlex

App web que calcula la ruta de inscripción semestre por semestre para estudiantes de Ingeniería de la Universidad Nacional de Colombia. Se ajusta cuando el estudiante pierde o aprueba una materia y evita cuellos de botella con los prerrequisitos.

Proyecto de Ingeniería de Software I, UNAL 2026-II.

## Tecnologías

Java 21, Spring Boot, Thymeleaf y SQLite.
